| Category | Key Services |

| **Storage** | Blob, Disk, Files, Queue, Table, NetApp Files |

| **AI + ML** | OpenAI Service, Cognitive Services, Machine Learning, Bot Service, Search |

| **DevOps** | DevOps Services, Pipelines, Boards, Artifacts, Repos |
| **Integration** | Logic Apps, Service Bus, Event Grid, Event Hubs, API Management, Functions |
| **Management** | Monitor, Log Analytics, Automation, Backup, Site Recovery, Cost Management |
| **Migration** | Azure Migrate, Data Box, Database Migration Service, Site Recovery |
