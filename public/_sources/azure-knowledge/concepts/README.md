## Quick reference

| Concept | Summary |
| --- | --- |
| Region | Geographic area containing one or more datacenters |
| Availability Zone | Unique physical location within a region (1+ datacenters) |
| Resource Group | Logical container for related Azure resources |
| Subscription | Billing and access control boundary |
| Management Group | Hierarchical container for managing access, policy, and compliance |
| Entra ID | Microsoft's cloud identity and access management service |
| Service Principal | Identity for applications to access Azure resources |
| Managed Identity | Automatically managed Azure AD identity for Azure services |
